当前代码在做什么

程序从 agent/demo.py 进入。它按参数选择一种大脑，从 data/conversation.json 读出历史，再调用 Agent.run。

  1. 进入选择一种大脑
  2. 读取JSON 里的历史
  3. 循环最多 6 步
  4. 写回保存全部消息

Agent.run 最多循环 6 步。每步向大脑要一个决定：final 结束并记下回答，tool 执行 TOOLS 里的函数并把结果写成下一条消息。finally 把全部消息写回 JSON。

三种大脑共用 decide(messages, tools)。

规则大脑

--rules 按本轮用户消息选择工具。看到工具结果后给出回答。不访问 Cursor。

Cursor 大脑

默认路径。阅读全部消息，并要求返回 JSON。调用时 tools=[]，仓库修改不发生在 SDK 里。

聊天接口

--chat 阅读全部消息，并要求返回 JSON。当前指向本机 Ollama 上的 Qwen2.5 14B。

在仓库根目录运行 python -m agent.demo。依据文件：agent/loop.py、agent/memory.py、agent/brain.py、agent/cursor_brain.py、agent/model_brain.py、agent/tools.py。

02实操

这一板块按一个主题动手做。当前主题是 LangChain。三步都调用 langchain-core，结果由本机接口返回。

LangChain 是什么

LangChain 是一个用来搭建大模型应用的 Python 框架。它把反复出现的零件收成库：提示词模板、对话模型、工具、输出解析，以及把这些零件接起来的写法。

提示词模板先写好消息骨架，把会变化的内容留成空位，例如 {topic}。调用时传入具体文字，空位才被填上。对话模型阅读填好的消息，生成下一段文字。工具是程序里的函数，有名称、说明和参数；模型可以要求执行它，真正运行函数的仍是程序。

这些零件都遵守同一套调用方式：invoke 负责启动。| 是管道，左边的产出原样交给右边。这套写法叫做 LCEL，英文是 LangChain Expression Language。官方文档把「模板、模型、工具、管道」当作搭建应用的基本组合。

下面三步不连接模型服务。第二步用一个本地函数站在对话模型的位置，专门让你看见管道送过去的内容。接上真实模型时，替换的是这个函数，前面的模板和 invoke 保持不变。
